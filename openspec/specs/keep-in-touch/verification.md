# Покрытие сценариев keep-in-touch

Карта связывает каждый сценарий с автотестом. Подробные API- и DB-проверки живут в `scripts/test-keep-in-touch.mts`, чистая логика — в `tests/keep-in-touch.test.ts`, главные пути пользователя — в `e2e/keep-in-touch.spec.ts`.

| Сценарий | Чем проверен |
| --- | --- |
| Новый контакт по умолчанию без напоминания | E2E `reminder frequency has a safe default...`; unit `does not create a deadline...` |
| Сохранение 7 / 30 / 90 / 365 дней | Integration: цикл по всем интервалам; E2E: сохранение и повторное открытие |
| Отсчёт от последнего известного общения | Unit `uses the latest known conversation...`; integration: расчёт по заметке |
| Неизвестная дата: отсчёт со включения | Unit `starts from reminder activation...`; integration: включение на контакте без истории |
| Смена активного интервала не сбрасывает точку отсчёта; повторное включение сбрасывает | Integration: последовательность enable/change/disable/re-enable |
| На границе срока контакт ещё не просрочен | Unit parameterized test для 7 / 30 / 90 / 365 |
| День равен 24 часам независимо от DST | Unit `uses 24-hour days across a daylight-saving transition` |
| Просроченные контакты отсортированы и открывают карточку | E2E `due contacts are sorted...`; integration: вторичная сортировка |
| Пустое состояние, ошибка и повтор | E2E: пустое состояние после отключения; mobile/error E2E: реальный сбой DB и успешный retry |
| Новая заметка сбрасывает срок; исправление не сбрасывает | E2E: исчезновение из блока; mobile E2E: создание и исправление; integration: даты в DB |
| Отключение напоминания убирает контакт; ошибка не меняет данные | E2E: отключение; integration: DB failure без частичной записи |
| Блок обновляется сам и при возврате в окно | Mobile/time E2E: появление контакта после минутного таймера |
| Мобильная ширина, клавиатура и отсутствие внешних уведомлений | E2E: viewport 390×844, контроль horizontal overflow и открытие карточки клавишей Enter; внешние уведомления не входят в архитектуру и исходный код |

Все три уровня запускаются в CI на каждый pull request.
