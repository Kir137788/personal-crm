# Круг — личная CRM

Люди, откуда вы знакомы, контакты и заметки после разговоров. Без регистрации, уведомлений и офлайн-режима.

## Запуск

Требуются Node.js 24 LTS, pnpm и запущенный Docker Desktop.

```bash
cd "/Users/kirprovans/Desktop/Курс/module-1/personal-crm"
docker compose up -d --wait
pnpm install
pnpm db:migrate
pnpm db:seed
pnpm build
pnpm start
```

Откройте http://127.0.0.1:3000. Для разработки вместо двух последних команд используйте `pnpm dev`. Приложение работает на Mac, в Docker — только PostgreSQL 18.

Настройки подключения уже находятся в `.env`. Не публикуйте этот файл. На новой машине заполните переменные, перечисленные в `.env.example`: POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_PORT и DATABASE_URL. Значения в пример не включены. Порт по умолчанию — 5432, адрес базы — 127.0.0.1. DATABASE_URL должен соответствовать остальным параметрам. Пароль не выводится приложением или скриптами.

## Проверка главного сценария

1. Откройте приложение: все контакты доступны в списке по 50 на страницу.
2. Нажмите «Добавить контакт». Имя обязательно; остальные поля необязательны.
3. Закройте карточку и найдите контакт через поле поиска (или ⌘ K).
4. Откройте карточку, допишите заметку, нажмите «Сохранить».
5. Перезагрузите страницу или откройте тот же адрес в другом браузере: контакт и заметка сохранятся.

Поиск не зависит от регистра и работает по всему списку, включая имя, почту, телефон и контекст знакомства. Контакты сортируются по имени. При закрытии карточки с несохранённым текстом приложение просит подтверждение. Если заметка уже изменена в другом окне, приложение не перезаписывает её молча.

## Данные и архитектура

- Next.js App Router, React, TypeScript, Tailwind CSS, локальные компоненты shadcn/ui.
- Браузер обращается только к Next.js API. Доступ к PostgreSQL через Drizzle выполняется на сервере.
- `lib/schema.ts` — схема; `drizzle/` — SQL-миграции и журнал миграций.
- `pnpm db:generate` — создать миграцию после изменения схемы.
- `pnpm db:migrate` — применить миграции.
- `pnpm db:seed` — добавить 1000 вымышленных контактов. Повторный запуск не создаёт дубликаты и не перезаписывает имеющиеся записи.
- Тестовые адреса используют домен example.com; реальные телефонные номера не генерируются.
- После проверки интерфейса дополнительно сохранён один учебный контакт «Вера Тестовая» с заметкой, всего 1001 запись.
- `pnpm typecheck` и `pnpm build` — проверка типов и production-сборки.
- `pnpm-lock.yaml` фиксирует версии зависимостей.

Данные сохраняются в именованном Docker volume `personal-crm_postgres_data`. `docker compose down` останавливает базу с сохранением данных. Не используйте `down -v`, если данные нужно сохранить.

## Работа в Codex

Откройте эту папку как основной локальный проект. `AGENTS.md` подключает инструкции `CLAUDE.md` и запрещает чтение `.env*`. В `.codex/config.toml` задан профиль запрета чтения. Конфигурация загружается в новом сеансе доверенного проекта; управляемые настройки приложения могут иметь приоритет. Скрипты приложения и Compose используют переменные внутри процесса, без вывода секретов.
